## English

### About the Original Mod

**Majrusz's Accessories** is a Minecraft mod created by **[Majrusz](https://github.com/Majrusz)** that adds new special accessories to make certain aspects of the game more enjoyable. The original mod is available for Forge, NeoForge, Fabric and Quilt on Minecraft 1.18.2 – 1.20.2.

- Original repository: <https://github.com/Majrusz/MajruszsAccessories>
- Original Modrinth page: <https://modrinth.com/mod/majruszs-accessories>
- License: **MIT**

### About This Port

This project is a faithful port of **Majrusz's Accessories** to **Minecraft 1.21.1 / NeoForge**, ported by **Accidey**.

All accessory designs, gameplay mechanics, textures and the original code are the work of **Majrusz**. This project only adapts the original mod to the NeoForge 1.21.1 platform, bundles the required **Majrusz Library**, and adds simplified Chinese localization for the ported version.

### Features

- **20+ special accessories** — each grants unique passive bonuses, covering mining, fishing, farming, breeding, trading, brewing, archaeology, sleeping and more.
- **Tier system** — accessories come in three tiers (1–3 booster slots), letting you customise their efficiency.
- **Accessory Boosters** — enhance accessories with random efficiency bonuses (configurable range, default -60% to +60%).
- **Cards** — reroll, remove or negate the efficiency bonus on any accessory.
- **Curios integration** *(optional)* — equips accessories in two custom Pocket slots when Curios API is installed.
- **Fully configurable** — every bonus value and drop chance can be adjusted in the config file.

### Requirements

| Dependency | Version | Required |
|---|---|---|
| Minecraft | 1.21.1 | ✅ |
| NeoForge | 21.1.249+ | ✅ |
| Majrusz Library | bundled with this port | ✅ |
| Curios API | 9.0.0+ | ❌ optional |

### Installation

1. Install **NeoForge** for Minecraft 1.21.1.
2. Download this mod and place the `.jar` file into your `.minecraft/mods` folder.
3. (Optional) Install **Curios API** to enable the Pocket slots.
4. Launch the game.

## 中文

### 关于原版模组

**Majrusz的饰品（Majrusz's Accessories）** 是由 **[Majrusz](https://github.com/Majrusz)** 创作的 Minecraft 模组，添加了各种特殊饰品，让游戏中的某些方面更加有趣。原版模组支持 Forge、NeoForge、Fabric 和 Quilt，对应 Minecraft 1.18.2 – 1.20.2。

- 原项目仓库：<https://github.com/Majrusz/MajruszsAccessories>
- 原版 Modrinth 页面：<https://modrinth.com/mod/majruszs-accessories>
- 许可证：**MIT**

### 关于本移植版

本项目由 **Accidey** 将 **Majrusz's Accessories** 忠实移植至 **Minecraft 1.21.1 / NeoForge**。

所有饰品设计、游戏机制、贴图以及原始代码均出自 **Majrusz** 之手。本项目仅将原模组适配至 NeoForge 1.21.1 平台，内置了所需的 **Majrusz Library**，并为移植版补充了简体中文本地化。

### 功能特性

- **20 余种特殊饰品** —— 每种饰品都提供独特的被动增益，涵盖挖矿、钓鱼、农业、繁殖、交易、酿造、考古、睡眠等玩法。
- **等级系统** —— 饰品分为三个等级（1–3 个配件槽位），可自由定制效果强度。
- **饰品配件** —— 为饰品附加随机的效果加成（范围可在配置文件中调整，默认 -60% 至 +60%）。
- **卡牌系统** —— 可重新随机、移除或取反任意饰品上的效果加成。
- **Curios 集成** *（可选）* —— 安装 Curios API 后，饰品可装备在两个自定义口袋槽位中。
- **完全可配置** —— 所有增益数值与掉落概率均可在配置文件中调整。
